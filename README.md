# LlanquihueTour

Proyecto desarrollado en Java para la Actividad Sumativa 1.

## Descripción

Sistema orientado a objetos para la agencia de turismo Llanquihue Tour.

## Clases implementadas

- Persona (clase base)
- Direccion (composición)
- GuiaTuristico (herencia de Persona)

## Estructura

- app
  - Main.java
- model
  - Persona.java
  - Direccion.java
  - GuiaTuristico.java
